### 문제 정의

- 누가
    - 노령견 또는 질병견을 케어하는 보호자

- 어떤 상황에서
    - 반려동물이 배변패드 위에서 배변 활동을 할 때

- 어떤 불편을 겪는가
    - 배변 훈련 중인 강아지에게 적절한 타이밍에 보상을 주기 어려워 훈련 효율이 떨어진다.
    - 대소변이 장시간 방치될 경우 악취, 세균 번식, 곰팡이 발생으로 이어질 수 있다.
    - 강아지가 오염된 패드를 밟거나, 오염된 패드 위에 다시 배변하지 않으려 하면서 바닥이나 카펫에 실수할 수 있다.
    - 병원 방문 시 배변 횟수나 상태에 대한 객관적인 정보가 필요하지만, 보호자의 기억에 의존해야 하는 경우가 많다.

### 솔루션 (한 줄)

- 배변패드 위의 배변 활동을 감지하고 보호자에게 알림을 제공한다.

### 기술/플랫폼 선택

| 선택한 것             | 근거                                             |
|-------------------|------------------------------------------------|
| Arduino Uno       | 센서 기반 프로토타입을 구현하기 쉽고, 팀이 빠르게 테스트할 수 있는 보드이기 때문 |
| 초음파 센서            | 패드 위에 대변과 같은 물체가 남아 있는지 높이 변화를 통해 감지하기 위해 사용   |
| 물높이 센서 / 수분 감지 센서 | 소변으로 인한 수분 변화를 감지하기 위해 사용                      |
| LED               | 센서 감지 여부를 시각적으로 확인하기 위해 사용                     |
| Arduino IDE       | Arduino Uno를 프로그래밍하고 센서 값을 확인하기 위해 사용          |
| Compose Multiplatform | 하나의 Kotlin 코드베이스로 Android와 iOS 양쪽 모바일 앱을 동시에 개발할 수 있어, 다양한 반려인 사용자층을 모두 커버 가능 |

### 선택하지 않은 옵션

| 후보            | 검토했지만 선택하지 않은 이유                                                              |
|---------------|-------------------------------------------------------------------------------|
| 온습도 센서        | 주변 환경의 온도와 습도 측정에는 적합하지만, 배변패드 위의 대소변을 직접 판별하기에는 정확성이 떨어진다고 판단                |
| 서버            | 1차 MVP에서는 배변 감지 자체를 검증하는 것이 우선이라고 판단                                          |
| 배변패드 자동 교체 기능 | 기계 구조와 모터 제어가 추가되어 구현 범위가 커지기 때문에 1차 MVP에서는 제외                                |
| 배변 기록 기능      | 알림 이후의 확장 기능으로 보고 1차 MVP에서는 실시간 감지와 알림에 집중                                    |

### MVP 범위

| 만들 것               | 만들지 않을 것         |
|--------------------|------------------|
| 배변 감지 기능           | 서버               |
| 소변 감지 기능           | 배변패드 자동 교체       |
| 대변 감지 기능           | 배변 기록 저장         |
| LED를 활용한 감지 결과 표시  | 정교한 건강 분석 기능     |
| 모바일 앱을 통한 알림 구조 구상 | 상용 제품 수준의 케이스 제작 |

### 검증 방법 초안

- 성공/실패를 판단할 기준
    - 배변패드 위에서 소변 또는 대변에 해당하는 상황이 발생했을 때, 센서가 이를 감지하고 LED로 상태를 표시할 수 있는가
    - 소변과 대변을 서로 다른 조건으로 구분할 수 있는가
    - 실제 반려견 환경에서 배변 활동을 누락 없이 감지하여 모바일 기기로 알림을 전송하는가

- 어떻게 측정할 것인가
    - 소변 대체제로 물을 활용하여 수분 감지 센서가 반응하는지 확인한다.
    - 대변 대체제로 부피와 질량이 비슷한 물체를 활용하여 초음파 센서가 높이 변화를 감지하는지 확인한다.
    - 감지 결과를 LED로 표시하여 정상적으로 인식되는지 확인한다.
    - 반복 테스트를 통해 오탐지와 미탐지 여부를 확인한다.

## B. 회고

### 가장 어려웠던 의사결정

- MVP 범위 설정이 가장 어려웠다.
    - 처음에는 서비스 사용 대상자를 동물병원 관계자로 설정했지만, 아이디어를 구체화하는 과정에서 노령견, 질병견, 배변 훈련 중인 강아지를 돌보는 보호자까지 문제를 확장할 수 있다고 판단했다.
    - 초기에는 강아지 스마트 하우스처럼 다양한 기능을 포함하는 방향도 고민했지만, 구현 범위가 넓어질수록 핵심 문제가 흐려질 수 있다고 느꼈다.
    - 따라서 1차 MVP에서는 배변패드 위의 배변 감지와 알림에 집중하기로 결정했다.

### 가장 의심스러운 가정 1가지

- 소변과 대변을 센서만으로 안정적으로 구분할 수 있을지 의심스럽다.
    - 소변은 수분 감지 센서를 통해 비교적 명확하게 감지할 수 있을 것으로 예상된다.
    - 하지만 대변은 크기, 모양, 위치, 질감에 따라 초음파 센서의 반응이 달라질 수 있다.
